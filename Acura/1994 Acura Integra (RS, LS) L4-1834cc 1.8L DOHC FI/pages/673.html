Idle Control System (Warm Engine RPM Too Low)


Check According To Following Conditions:

1. Idle RPM is below Specification (No Load)
a. Idle Air Control (IAC) Valve (Diagnostic Trouble Code (DTC) 14)
b. Idle Adjusting Screw
2. Idle speed does not increase after initial start up
a. IAC Valve (DTC 14)
3. On models with automatic transmission, the idle speed drops in gear
a. A/T Shift Position Signal
b. IAC Valve
4. Idle speed drops when air conditioner is on
a. Air Conditioning Signal
b. IAC Valve (DTC 14)
5. Idle speed drops when steering wheel is turning
a. P/S Oil Pressure Switch Signal
b. IAC Valve (DTC 14)
6. Idle speed fluctuates with electrical load
a. IAC Valve (DTC 14)

(Back Up mode is indicated when the MALFUNCTION INDICATOR LAMP (MIL) is on. Jump the service check connector, if no code is displayed (MIL stays on steady), the back-up system is in operation.
