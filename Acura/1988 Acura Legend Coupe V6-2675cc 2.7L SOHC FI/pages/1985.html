DTC List - Fuel and Emissions





Trouble Code Index
If Red LED indicates CODE 11, 16 or exceeds 18, count the number of blinks again, if the indicator is in fact blinking these codes, substitute a known-good ECU and recheck. If the indication goes away, replace the original ECU.
The Check Engine dash warning light and ECU Red LED may come on, indicating a system problem, when, in fact, there is a poor or intermittent electrical connection. First, check the electrical connections, clean or repair connections if necessary.
