Special Installation Instructions

1. Remove the cooler pipes and fittings, speed sensor and throttle cable bracket from the failed transmission.

2. Flush the cooler pipes and fittings. Install them, the speed sensor, and throttle cable bracket on the remanufactured transmission.

3. Install the transmission as described in the service manual.

4. Flush the transmission cooler, hoses and lines.

NOTICE
Failure to flush the transmission cooler, hoses, lines, pipes, and fittings could cause damage to the replacement transmission.

5. Install the transmission filter kit (included with the remanufactured transmission).

6. Fill the transmission with Genuine Honda ATF, P/N 08206-9001.
