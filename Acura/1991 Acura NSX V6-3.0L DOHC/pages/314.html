After Warm Up

Frequent Stalling After Warm Up
Check:

1. Idle Controls
- Idle Adjusting Screw
- Electronic Idle Control Valve (EACV)
2. Fuel Pressure Regulator
3. EGR Control System
4. Atmospheric Pressure (PA) Sensor (13)
5. ECU (BU)

NOTE:
All items should be checked in the order in which they appear.
A (number) after the component indicates the fault code associated with that system. (BU): When the Check Engine light and the self-diagnosis indicator are on, the back-up system is in operation.
