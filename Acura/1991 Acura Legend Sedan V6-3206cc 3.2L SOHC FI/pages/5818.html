Fuel Return Line: Description and Operation

Fuel Delivery System:





The fuel return line carries excess fuel from the fuel pressure regulator back to the tank. It is routed under the left side of the chassis from the fuel tank to the injection manifold. The fuel return line is a steel bundy-pipe style and is referred to as a fuel return pipe in the illustration.
