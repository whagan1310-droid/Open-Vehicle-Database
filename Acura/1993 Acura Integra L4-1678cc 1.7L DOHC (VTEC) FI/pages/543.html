Engine Difficult to Start When Warm

Check in Order Listed:

^ Engine Control Module
Check Malfunction Indicator Light (MIL) action (see Diagnostic Trouble Code Extraction). Is MIL coming on/are codes stored/is light on steady?

^ Engine Coolant Temperature (ECT) Sensor
Perform Engine Coolant Temperature Sensor tests as shown for DTC 6.

^ Fast Idle Thermo Valve
Perform Fast Idle Thermo Valve test to verify air flow when cold.

^ TDC/CKP/CYL Sensor
Perform TDC/CKP/CYL Sensor tests as shown for DTC's 4, 8 & 9.

^ Manifold Absolute Pressure (MAP) Sensor
Perform MAP Sensor tests as shown for DTC's 3 & 5.

^ Barometric Pressure (BARO) Sensor
Perform BARO Sensor tests as shown for DTC 13.
