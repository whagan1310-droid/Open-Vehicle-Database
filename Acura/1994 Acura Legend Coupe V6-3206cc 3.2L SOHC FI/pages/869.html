Emission System Application Chart

Engine Displacement 3.2 Liter (3,206 cc)
Fuel System PGM-FI [1]

Emission Control Devices and Systems:
TWC Three-Way Catalytic Converter
CEC Computerized Engine Controls
EFI Electronic Fuel Injection
EGR Exhaust Gas Recirculation
EVAP Evaporative Emission Control
FR Fill Pipe Restrictor
MIL Malfunction Indicator Light
HO2S [2] (Heated) Exhaust Gas Oxygen Sensor
PCV Positive Crankcase Ventilation
SPK Spark Controls


Remarks:
[1] Programmed Fuel Injection
[2] Right and Left Heated Oxygen Sensors.

Emission Control System (ECS) Configuration Label
An ECS Configuration Label is attached underneath the hood. It contains engine application and emission control information, vacuum hose routing diagram and engine adjustment information.
