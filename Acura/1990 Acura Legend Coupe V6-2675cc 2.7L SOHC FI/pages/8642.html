Dashlight Brightness Control
Control Unit Input Test
Remove the dashboard lower panel and disconnect the 6-P connector from the control unit.
Make the following input tests at the harness pins. If all tests prove OK, yet the dash lights still cannot be controlled, check the connector for a good connection. If OK, substitute a known-good control unit and recheck.
