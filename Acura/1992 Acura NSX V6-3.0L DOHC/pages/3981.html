Mode Control Motor

Mode Control Motor Replacement




1. Remove the mounting screws, then remove the mode control motor.
2. Install the mode control motor in the reverse order of removal. Then apply battery voltage, and watch the doors move.
^ Make sure that the HEAT and DEF doors moves smoothly without binding.
^ Make sure the motor doesn't pull the HEAT and DEF doors too far.
