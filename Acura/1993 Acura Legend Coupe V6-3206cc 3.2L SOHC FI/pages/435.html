Engine Difficult to Start When Cold

Check:

1. PGM-FI Control (ECM) Unit (BU)
a. Coolant Temperature (ECT) Sensor (code 6)
b. TDC/CRANK/CYL Sensor (code 4,54,9,59)
c. Manifold absolute pressure (MAP) sensor (code 3,6)
d. Barometric Pressure (BARO) Sensor (code 13)
2. Fuel Supply
a. Fuel Pump
b. Contaminated Fuel
3. Idle Control System
a. Fast Idle Thermo Valve
b. Starting Air Valve
c. Starter Switch Signal


NOTE: All items should be checked in the order in which they appear. A (number) after the component indicates the fault code associated with that system. If BU appears on with PGM-FI unit, it indicates the vehicle is running in back-up mode.
