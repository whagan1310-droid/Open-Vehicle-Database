RPM Too High When Warm

Check:

1. Idle Control System
a. Idle Air Control Valve (IAC) (14)
b. Fast Idle Thermo Valve
c. Hoses and Connections
d. Idle Adjusting Screw
e. Power Steering Pressure Switch Signal
2. Engine Coolant Temperature (ECT) Sensor (6)
3. Air Intake System
a. Throttle Body
b. Throttle Cable
4. PGM-FI Control (ECM) Unit (BU)

NOTE: All items should be checked in the order in which they appear. A (number) after the component indicates the fault code associated with that system. If BU appears on with PGM-FI unit, it indicates the vehicle is running in back-up mode.
