Brake Warning Indicator: Description and Operation

The brake system indicator circuit turns on the brake system indicator light to alert the driver that the parking brake is applied, or that the brake fluid level is low. The light is also turned on by the "safety circuit" and the "test during START" circuit.



Parking Brake

With the ignition in RUN or START battery voltage is supplied through fuse 5 and the brake system indicator light to the parking brake switch. With the parking brake on, the switch is closed, providing a ground for the light. The brake system indicator light reminds the driver that the parking brake is applied.



Brake Fluid Level

With the ignition in RUN or START battery voltage is supplied through fuse Sand the brake system indicator light to the brake fluid level switch. If the brake fluid level is low, the brake fluid level switch closes, and ground is provided to the circuit, turning on the brake system indicator light.


NOTE: Check the brake system for brake pad wear and fluid leaks before adding brake fluid.



Bulb Check

When the ignition switch is first turned to RUN, the "safety indicator" circuit in the gauge assembly tests the brake system indicator light by supplying a ground for several seconds to turn it on. When the ignition is turned to START the "test during START" circuit tests the light by grounding it. With the ignition switch in RUN or START battery voltage is supplied through fuse 5 and the YEL wire to the gauge assembly. With the ignition switch in START battery voltage is supplied through fuse 7 and the BLK/WHT wire to the gauge assembly.
