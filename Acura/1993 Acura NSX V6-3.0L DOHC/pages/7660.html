DTC 36


The Malfunction Indicator Lamp indicates Diagnostic Trouble Code 36: A problem in the traction control TCFC signal.











The engine control module outputs the TCINH signal to the traction control system control unit when the correct TCFS signal and TCFC signal have been input to it from the traction control system control unit.
