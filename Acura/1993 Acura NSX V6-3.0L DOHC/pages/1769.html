Using Digital Multimeter (KS-AHM-32-003)




HOW TO DISPLAY AND READ DIAGNOSTIC TROUBLE CODES
Connect the wire harness to the Test Harness, and/or connect the Test Harness to the Transmission Control Module (TCM) according to the troubleshooting flowchart.

NOTE:
- Only the A and D terminals of the Test Harness are used for A/T troubleshooting.
- Unless otherwise noted, use only the Digital Multimeter, KS-AHM-32-003, for testing.
