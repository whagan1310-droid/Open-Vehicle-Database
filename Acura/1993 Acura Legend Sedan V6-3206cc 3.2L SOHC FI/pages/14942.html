Connecting Rod: Service and Repair

Fig. 81 Main Bearing Identification:





1. Marks are stamped on the end of the engine block as a code for each main journal bore, Fig. 81. Use these marks in conjunction with numbers stamped on crankshaft to select correct bearings.

Fig. 84 Connecting Rod Bearing Identification:





2. Numbers are stamped on the side of each connecting rod to code the size of the large end. Use these numbers in conjunction with letters stamped on crankshaft, Fig. 84, to select correct bearings.
3. A bearing cap bridge is used to increase torsional rigidity. When installing main bearings, first torque main bearing cap bolts to 29 ft. lbs., then torque 11 mm bridge bolts to 49 ft. lbs., working diagonally from center of bridge.
4. Torque side cap bolts to 36 ft. lbs.
