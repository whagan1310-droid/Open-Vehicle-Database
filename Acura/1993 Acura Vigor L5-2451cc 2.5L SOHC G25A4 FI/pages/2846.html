Failure Mode D: Cowl Sensor Short or Dash Sensor Open



1. Disconnect battery ground cable, then positive cable.
2. Turn ignition switch Off, then wait at least three minutes to allow capacitor in back-up circuit to discharge, then disconnect airbag connector.
3. Install short connector (red) on airbags and seat pretensioners, install short connector A (Tool No. 07MAZ-SP00200) on drivers airbag cable reel connector, then one on SRS main harness connector (for passenger side airbag). This will prevent any static electricity from triggering seat belt pretensioners.
4. Connect test harness B between SRS unit and SRS main harness 18-P connector, check resistance between left dash sensor terminals B12 and B16, and between right dash sensor terminals B4 and B6, if resistance is greater that 5,000 ohms, proceed to step 5. If resistance is less than 5,000 ohms, SRS unit is faulty, substitute with known good unit, then recheck voltage.
5. Connect test harness D between dash sensor and SRS main harness 2-P connector, check resistance between terminal Nos. 1 and 2, if resistance is greater than, 5,000 ohms, that dash sensor is faulty, replace and recheck voltages. If resistance is less than 5,000 ohms, the SRS main harness is faulty, replace and recheck voltages.
