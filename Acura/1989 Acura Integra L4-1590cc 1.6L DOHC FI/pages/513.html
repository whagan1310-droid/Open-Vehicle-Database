Resonator Control System

Intake System Schematic:





The resonator control system is used to help lower intake noise from the engine compartment. The resonator control solenoid is powered whenever the ignition switch is turned ON, from terminal Ign. 1. Source vacuum is routed to the solenoid through a check valve and surge tank to supply a constant vacuum source. When engine speed is below 3,000 rpm, the ECU grounds pin A10 which opens the solenoid. When opened the solenoid allows vacuum to the resonator diaphragm, which opens the resonator chamber.
