Antitheft and Alarm Systems: Description and Operation

The security system is passively activated when you remove the key from the ignition, and lock the doors with the driver's door key, lock knob locks, or the passenger's door key lock. The keyless entry option may be used to arm or disarm the security system. There is a delay of about 15 seconds from the time the doors are closed (and locked) to system arming. The red security indicator on the driver's door will flash when the system is armed. When the system is armed, the alarm will go off if any of the four doors, hood, or trunk is opened.


The alarm will also go off it the radio is removed or if the wiring to the radio is cut. When the system is set, the master key can open the trunk without triggering the alarm. The alarm will go off if the trunk lock is smashed, or the trunk is opened with the release button on the driver's door.


The security system will not set if the hood, trunk, or any door is not latched completely. If the battery terminal(s) are disconnected when the system is set, the alarm will go off when the cables are reconnected.


The security system disables the starter relay, sounds both horns, and flashes the low beam headlights, side marker lights, turn signals, and taillights. The alarm will continue for two minutes before resetting itself, or until the system is disarmed by unlocking either front door from the outside with a key.


Theft Protection (4LS)


The audio system disables itself whenever the radio/player unit is disconnected from the battery. To use the radio again you must enter a five-digit code with the station preset buttons.
