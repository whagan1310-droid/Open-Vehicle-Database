SRS - No Shortcuts, No Probes, No Paint

SRS: No Shortcuts, No Probes, No Paint

No short cuts:
Unfortunately, there are no shortcuts when it comes to SRS troubleshooting. (But if we ever find any, you'll be the first to hear.) When the SRS indicator light stays on, you have to perform all the voltage checks in the S/M. And if you have to call Tech Line about an SRS problem, be sure you have all the voltages written down. No probe's: Never probe an SRS connector from either the terminal or the wire side. The terminals are gold plated and easily damaged. If you don't have the correct test harness, you'll have to get one before you can do any testing.

No paint:
If there's a cosmetic problem with an airbag assembly, replace it. Don't try to paint it. No testing has been done for paint compatibility or for possible paint or solvent penetration.
