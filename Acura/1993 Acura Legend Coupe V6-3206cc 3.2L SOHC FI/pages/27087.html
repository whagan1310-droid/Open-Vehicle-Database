Temporary Driving Conditions

1. The anti-lock warning lamp will come on and control unit will store problems in memory under the following conditions:
a. Problem code 5, 5-4 and 5-8, tire adhesion lost due to excessive cornering speed.
b. Problem code 4-1, 4-2, 4-4 and 4-8, vehicle loses traction when starting from a stuck condition.
c. Problem code 2, 2-1 parking brake is applied for more than 30 seconds while vehicle is being driven.
d. Vehicle is driven over extremely rough roads.
2. If anti-lock warning lamp goes off after engine is turned off, than back on, ABS is operating normally.
