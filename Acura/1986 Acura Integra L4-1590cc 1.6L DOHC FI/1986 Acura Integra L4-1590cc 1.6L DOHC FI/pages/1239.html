PGM-FI - Warning Light Blinking Code 1

86acura01

July 7, 1986
YEAR MODEL APPLICATION
1986 INTEGRA See VEHICLES
AFFECTED
86-007
Integra PGM-FI Warning Light

PROBLEM

PGM-FI warning light illuminates and ECU LED blinks Code 1 while driving in higher ambient temperatures.

VEHICLES AFFECTED

Up to VIN DA1-S006009 Up to VIN DA3-S005952

CORRECTIVE ACTION

Install a purge jet in the purge hose on throttle body.

1. Disconnect the red braided purge hose from the top of the throttle body. Check to see if there is a jet already installed in the hose. If there is a jet, call Emissions Techline. If there is no jet, proceed to the next step.

2. Insert the purge jet approximately 1" into the hose.

3. Reconnect the purge hose to the throttle body.

4. Remove the fuse at the battery positive terminal for 10 seconds to reset the ECU, then reinstall.

PARTS INFORMATION

50 purge jets will be sent to each dealer and charged to dealer accounts. Use the following part number to order additional jets:

Purge jet: P/N 99105-PG7-000AH
