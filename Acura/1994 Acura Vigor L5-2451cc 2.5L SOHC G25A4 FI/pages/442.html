Symptom Troubleshooting Index

PROCEDURE

Across each row in the chart, the systems that could be sources of a symptom are ranked in the order they should be inspected starting with "1". Find the symptom in the left column, read across to the most likely source, then refer to the co9mponent or system listed at the top of that column. If inspection shows the system is OK, try the next most likely system "2", etc.









NOTE:
- If codes other then those listed above are indicated, count the number of blinks again. If the MIL is in fact blinking these codes, replace the engine control module.
- If the MIL is on while the engine is running, jump the service check connector. If no code is displayed (MIL stays on steady), the back-up "BU" system may be in operation. Substitute a known-good engine control module and recheck. If the indication goes away, replace the original engine control module.
