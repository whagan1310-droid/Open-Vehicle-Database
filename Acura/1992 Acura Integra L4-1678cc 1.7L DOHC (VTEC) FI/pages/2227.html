DTC List - Transmission Control





Trouble Code Descriptions and Symptom Index

NOTE:
- If a customer describes the symptoms for codes 3, 6 or 11, yet the LED is not blinking, it will be necessary to recreate the symptom by test driving, and then checking the LED with the ignition still ON.
- If the LED display blinks 12 or more than 13 times, the A/T control unit is faulty.
- S3 indicator light and engine warning light may come on simultaneously. If so, check the PGM-FI system according to the number of blinks on the PGM-FI ECU self-diagnosing indicator, then reset the memory by removing the alternator sensor fuse (1OA) in the under-hood relay box for more than 10 seconds. Drive the vehicle for several minutes at speed over 30 mph, then recheck the lights.
