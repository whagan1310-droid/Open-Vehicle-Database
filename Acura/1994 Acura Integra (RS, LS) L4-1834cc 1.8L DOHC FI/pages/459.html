After Warm Up

Check in Order Listed

1. Idle Control System
a. Idle Air Control Valve (Diagnostic Trouble Code (DTC) 14)
b. Idle Adjusting Screw
2. Fuel Supply
a. Injector Resistor
b. Fuel Injector
c. Contaminated Fuel
3. Barometric Pressure (BARO) Sensor (DTC 13)
4. Engine Control Module in Back Up Mode

Back Up mode is used when the Malfunction Indicator Lamp (MIL) is on. Jump the service check connector, if no DTC is displayed (MIL stays on steady), the back-up system is in operation.
