Antitheft and Alarm Systems: Description and Operation

The security system is passively armed when you remove the key from the ignition and lock the doors with the driver's door key lock or knob lock or the passenger's door key lock, The keyless entry option also arms or disarms the security system. There is a delay of approximately 15 seconds from the time the doors are closed (and locked) to system arming.

With the system armed, the illegal entry mode alarm will go off if the driver's door, passenger's door, engine compartment lid, hood, or trunk is opened. The alarm will also go off if the radio is removed. With keyless entry, the "panic button" may also be used to set off the alarm.

The alarm system disables the starter cut relay, sounds all three horns, and flashes the interior, tail, side marker, parking, and turn signal lights, and headlight low beams. The front headlight retractors are opened by the security control unit so the headlights will be seen. The alarm will continue for about 2 minutes and then reset itself.
