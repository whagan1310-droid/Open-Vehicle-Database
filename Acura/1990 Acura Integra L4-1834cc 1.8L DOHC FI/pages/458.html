After Warm Up

Frequent Stalling After Warm Up
Check



1. Idle Control System
- Electronic Air Control Valve (EACV) (14)
- Idle Adjusting Screw
2. Fuel Supply
- Fuel Injector (16)
- Fuel Pump
- Fuel Filter
3. EGR Control System (A/T Only)
4. PGM-FI Control (ECU) Unit (BU)

NOTE: All items should be checked in the order in which they appear. A (number) after the component indicates the fault code associated with that system. If BU appears on with PGM-FI unit, it indicates the vehicle is running in back-up mode.
