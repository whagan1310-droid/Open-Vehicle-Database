Function Test

1. With engine stopped, depress brake pedal several times, the depress pedal hard and hold for 15 seconds. If pedal sinks, master cylinder, brake line or brake caliper is faulty.
2. With brake pedal depressed, start engine. If pedal sinks slightly, vacuum booster is operating. If pedal height does not vary, booster or check valve is faulty.
