Engine Won't Start / No Start



Check in Order Listed:

1. Ignition Output Signal (Diagnostic Trouble Code (DTC) 15)
2. Fuel Injectors (DTC 16)
3. Fuel Supply
a. Main Relay
b. Fuel Pump
c. Fuel Filter
d. Contaminated Fuel
e. Injector Resistor
f. Fuel Injector
4. TDC/CKP/CYL Sensor (DTC 4,8,9)
5. Engine Control Module in Back Up mode

Back-Up mode is enabled when the MALFUNCTION INDICATOR LAMP (MIL) is on. Jump the service check connector, if no DTC is displayed (MIL stays on steady), the back-up system is in operation.
