Manual topics (scroll — select any)

Section and search apply when you open an Operation CHARM (remote) manual. Local exports open your files as usual; these fields are disabled for that vehicle.

Click the manual link to open the CHARM section (new tab). If the search box has text, use “Google · this folder” next to that link for a Google search scoped to the same path on charm.li — that uses a normal link so popup blockers cannot stop it.

Load CHARM table of contents (for search suggestions)

This page cannot read charm.li directly (browser security). If charm-section-toc-cache.json is present (build with scripts/build_charm_section_toc_cache.py), suggestions load automatically. Otherwise, after you open Repair and Diagnosis or Parts and Labor on charm.li, click Expand All, run the bookmarklet there, or paste JSON / one title per line below.

Add a new bookmark in your browser, paste the copied line as the URL, then open that bookmark while you are on the expanded CHARM page. It copies JSON to the clipboard.
