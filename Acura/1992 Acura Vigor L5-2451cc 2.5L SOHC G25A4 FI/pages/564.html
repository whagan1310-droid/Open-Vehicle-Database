Misfire or Rough Running

SYMPTOM: Misfire Or Rough Running

CHECK
1. Electronic Control Unit (ECU) (**)
2. Fuel Injectors (16)
3. Manifold Absolute Pressure Sensor (3) (5)
4. TDC/Crank/Cyl Sensor (4) (8) (9)
5. Exhaust Gas Recirculation System [Automatic Transmission] (12)

Numbers in parentheses are the blink codes displayed at the CHECK ENGINE LIGHT. (**) CHECK ENGINE LIGHT stays on without blinking. Notes on Reading Diagnostic List For ECU trouble code component testing procedures see COMPUTERIZED ENGINE CONTROLS.
