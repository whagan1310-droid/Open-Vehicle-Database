Loss of Power

Check in Order Listed

1. Fuel Supply
a. Fuel Filter
b. Contaminated Fuel
c. Fuel Pump
d. Injector Resistor
2. Throttle Position Sensor (Diagnostic Trouble Code (DTC) 7)
3. Air Intake System
a. Throttle Body
b. Intake Control System
4. Emission Controls
a. Catalytic Converter
5. Fuel Injectors (DTC 16)
6. Manifold Absolute Pressure Sensor (DTC 3)
7. Variable Valve Timing System (DTC 21 or 22)
8. Engine Control Module in Back Up Mode

Back-up mode is indicated when the MALFUNCTION INDICATOR LAMP (MIL) is on. Jump the service check connector, if no code is displayed (MIL stays on steady), the back-up system is in operation.
