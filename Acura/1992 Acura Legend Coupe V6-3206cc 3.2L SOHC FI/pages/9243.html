Audio - Erratic Remote Control Operation


9229acura01

YEAR
1991-92


MODEL
LEGEND


VIN APPLICATION
See VEHICLES AFFECTED


BULLETIN NO.
92-013


April 20, 1992


Remote Audio Volume Controls Inoperative or Cause Static


SYMPTOMS

1. The remote volume control switches (up and down) are inoperative, but the preset station select (AUDIO) button is functional.

OR

2. Static coming from the speakers when the remote volume control switches are used. This can occur during AM, FM, cassette or CD operation.


PROBABLE CAUSE

Defective volume control motor inside the audio unit.


VEHICLES AFFECTED

1991-92 Legend L Sedan 1991-92 Legend LS Sedan 1991-92 Legend LS Coupe


CORRECTIVE ACTION

Diagnose the symptoms carefully. If necessary, replace the audio unit with the appropriate unit listed in PARTS INFORMATION.

SYMPTOM 1
Replace the audio unit ONLY if the remote volume control switches DO NOT work, and the preset station select (AUDIO) button does.

NOTE:
If none of the remote controls work, refer to Service Bulletin 91-045, "Erratic Remote Audio Control Operation."

SYMPTOM 2
Replace the audio unit if static is heard from the speakers ONLY when the remote volume control switches are used.


There are other possible causes of static on Legend audio systems that are not related to the remote volume controls. Check for the following:

^ On LS models with Bose System: If static occurs only on the AM band, and the remote volume control switches are NOT being used, refer to Service Bulletin 92-001, "Static on AM Band".

^ If AM band reception is poor, or the system is picking up static from other sources, refer to Service Bulletin 91-053, "Poor Reception on AM Band".
