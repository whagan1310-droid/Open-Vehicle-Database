Engine Won't Start

Check:

1. Fuel Supply
a. Main Relay
b. Fuel Pump
c. Fuel Filter
d. Injector Resistor
e. Fuel Injector
f. Contaminated fuel
2. PGM-FI Control (ECM) Unit (0)
a. CKP/CYP Sensor
b. Ignition output signal
c. Engine coolant temperature sensor
3. Low battery voltage.

NOTE: All items should be checked in the order in which they appear. A (number) after the component indicates the fault code associated with that system. If BU appears on with PGM-FI unit, it indicates the vehicle is running in back-up mode.
