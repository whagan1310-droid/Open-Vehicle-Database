Fails Emission Test

SYMPTOM: Fails Emission Test

CHECK:
1. Electronic Control Unit (**)
2. Manifold Absolute Pressure Sensor (3) (5)
3. Oxygen Sensor (1) (2)
4. Coolant Temperature Sensor (6)
5. Catalytic Converter (TWC)
6. Evaporative Emission Controls (EVAP)
7. Positive Crankcase Ventilation

Numbers in parentheses are the blink codes displayed at the CHECK ENGINE LIGHT. (**) CHECK ENGINE LIGHT is not on, or stays on without blinking. Notes on Reading Diagnostic List For ECU trouble code component testing procedures see COMPUTERIZED ENGINE CONTROLS.
