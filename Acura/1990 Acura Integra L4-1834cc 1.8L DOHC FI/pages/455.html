Engine Difficult to Start When Cold


SYMPTOM:
Difficult To Start Cold.
CHECK
1. Electronic Control Unit (**)
2. Coolant Temperature Sensor (6)
3. Other Idle Controls
4. Manifold Absolute Pressure Sensor (3) (5)

Numbers in parentheses are the blink codes displayed on back of the ECU. (**) LED on the ECU is not on, or stays on without blinking. See NOTES ON READING DIAGNOSTIC LIST Article for more information. For ECU trouble code component testing procedures see Computers and Control Systems.
