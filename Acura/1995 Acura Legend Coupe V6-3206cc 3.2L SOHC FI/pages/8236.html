Automatic Climate Control

MODE CONTROL MOTOR REPLACEMENT
1. Remove the dashboard lower cover. Service and Repair
2. Disconnect the mode control motor connector.






3. Remove the mounting screws and mode control motor.
4. Install the mode control motor in the reverse order of removal. After installation, make sure the mode control motor operates smoothly.
