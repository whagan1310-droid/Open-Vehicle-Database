Engine Won't Start

Engine Won't Start
Check:

1. Fuel Supply
- Fuel Pump
- Main Relay
- Injector Resistor
2. ECU
3. Ingition Output Signal (15)


NOTE: All items should be checked in the order in which they appear. A (number) after the component indicates the fault code associated with that system.
