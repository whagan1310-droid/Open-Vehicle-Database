Emission System Application Chart


Engine Displacement 3.0 Liter (2,977 cc)
Fuel System PGM-FI

Emission Control Devices and Systems:
CAT Three-Way Catalytic Converter
CEC Computerized Engine Controls
CEL Check Engine Light
EFI Electronic Fuel Injection
EGR Exhaust Gas Recirculation
EVAP Evaporative Emission Control
FR Fill Pipe Restrictor
OXY [1] (Heated) Exhaust Gas Oxygen Sensor
PCV Positive Crankcase Ventilation
SPK Spark Controls


Remarks:
[1] Front and Rear Heated Oxygen sensors


Emission Control System (ECS) Configuration Label
An ECS Configuration Label is attached to bulkhead/firewall. It contains emission control information and vacuum hose routing diagram.
