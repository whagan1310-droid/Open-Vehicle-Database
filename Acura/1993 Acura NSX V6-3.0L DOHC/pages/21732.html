Interior Lighting Module: Description and Operation

The integrated control unit consists of several circuits combined in a single control unit. See the appropriate section of this manual for details about each circuit.


The integrated control unit receives battery voltage at all times through fuse 34. With the ignition switch in RUN or START, battery voltage is supplied through fuse 5 to the control unit. The control unit is grounded at G401.
