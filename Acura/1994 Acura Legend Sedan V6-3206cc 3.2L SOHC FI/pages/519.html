Idle Control System

IDLE CONTROL SYSTEM TROUBLESHOOTING GUIDE




NOTE:
- Across each row in the chart, the sub-systems that could be sources of a symptom are ranked in the order they should be inspected, starting with (1). Find the symptom in the left column, read across to the most likely source, then refer to the page listed at the top of that column. If inspection shows the system is OK, try the next system (2), etc.
- If the idle speed is out of specification and the Malfunction Indicator Lamp (MIL) does not blink code 14.
- M/T-equipped cars use an Engine Control Module (ECM). A/T-equipped cars use a Powertrain Control Module (PCM), which also controls transmission functions. When working on an A/T-equipped car, all references to ECM actually refer to the PCM.
