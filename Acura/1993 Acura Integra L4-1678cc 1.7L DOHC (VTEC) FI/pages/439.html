Misfire/Rough Running




Check in Order Listed

1. Fuel Supply
a. Manifold Absolute Pressure Sensor
b. Fuel Injector (Diagnostic Trouble Code (DTC) 16)
c. Pressure Regulator
d. Idle Air Control Valve (DTC 14)
2. TDC/CKP/CYL Position Sensor (DTC 4,8,9)
3. Engine Control Module running in Back Up mode


Back-up mode is indicated when the Malfunction Indicator Light (MIL) is on. Jump the service check connector, if no DTC is displayed (MIL stays on steady), the back-up system is in operation.
