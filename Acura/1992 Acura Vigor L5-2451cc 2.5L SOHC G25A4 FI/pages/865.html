EFI Electronic Fuel Injection
EGR Exhaust Gas Recirculation
EVAP Evaporative Emission Control

Emission Control System (ECS) Configuration Label
An ECS Configuration Label is attached underneath the hood. It contains emission control information, vacuum hose routing diagram and tune up information.
