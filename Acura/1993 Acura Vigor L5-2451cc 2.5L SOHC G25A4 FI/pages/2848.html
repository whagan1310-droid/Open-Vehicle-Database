Failure Mode F: Open In Airbag Inflator or Cable Reel

1. Disconnect battery ground cable, then positive cable.
2. Turn ignition switch Off, then wait at least three minutes to allow capacitor in back-up circuit to discharge, then disconnect airbag connector.
3. Do not disconnect drivers airbag connector for this test.
4. Install short connector (red) on airbags and seat pretensioners, install short connector A (Tool No. 07MAZ-SP00200) on drivers airbag cable reel connector, then one on SRS main harness connector (for passenger side airbag). This will prevent any static electricity from triggering seat belt pretensioners.
5. Connect test harness B between SRS unit and SRS main harness 18-P connector, measure resistance between terminal Nos. B1 and B7, if resistance is greater then 200 ohms, proceed to step 6. If resistance if less than 200 ohms, SRS unit in faulty, substitute known good SRS unit and recheck voltages.
6. Disconnect cable reel harness 7-P connector from SRS main harness, then connect test harness C only to cable reel harness side 7-P connector.
7. Measure resistance between terminal Nos. 4 and 5, if resistance is greater than 200 ohms, proceed to step 8, if less tan 200 ohms, SRS main harness is faulty, replace and recheck voltage.
8. Disconnect drivers side airbag 3-P connector from cable reel harness, then connect test harness C to drivers airbag 3-P connector.
9. On Legend models, measure resistance between terminal Nos. 9 and 10, if resistance is greater than 200 ohms, the inflator is faulty, replace and recheck voltages. If resistance is less than 200 ohms, the cable reel is faulty, replace and recheck voltages.
10. On Vigor models, measure resistance between terminal Nos. 7 and 8, if resistance is greater than 200 ohms, the inflator is faulty, replace and recheck voltages. If resistance is less than 200 ohms, the cable reel is faulty, replace and recheck voltages.
