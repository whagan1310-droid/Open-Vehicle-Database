Function Control Motor Does Not Run

Function control motor does not run.

1. Check the No. 22 and No. 26 fuses (engine compartment) and No. 16 fuse (under-dash fuse box).
2. Check the function control motor. If there is no problem, check for an open in the wire between the function control motor and function control unit. If there is still no problem, the control unit is defective.
