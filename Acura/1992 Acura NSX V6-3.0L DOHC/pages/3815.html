ABS - Problem Code 1 (Leaking Soleniod): Overview

YEAR
1991-92



MODEL
NSX



VIN APPLICATION
ALL



June 8, 1992



BULLETIN NO.
92-014



Anti-lock Brake System Problem Code 1/Leaking Solenoid



SYMPTOM

The Anti-lock Brake System indicator light comes on and the Anti-lock Brake System control unit indicates Problem Code 1. In some cases, the top of the modulator reservoir may be wet with brake fluid.


PROBABLE CAUSE

A leaking modulator solenoid that prevents the pump from pressurizing the accumulator to the prescribed level within the pump running limit of 120 seconds.


CORRECTIVE ACTION

Perform a solenoid leak check and, if necessary, flush or replace the solenoids. Check the solenoids before going through the Problem Code 1 troubleshooting in the service manual.
