DTC 7

The Malfunction Indicator Lamp indicates Diagnostic Trouble Code 7: A problem in the throttle position sensor circuit.








The throttle position sensor is a potentiometer. It is connected to the throttle valve shaft. As the throttle position changes, the throttle position sensor varies the voltage signal to the engine control module.
