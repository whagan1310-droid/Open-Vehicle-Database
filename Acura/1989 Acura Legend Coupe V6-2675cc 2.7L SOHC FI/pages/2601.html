DTC 3

Code 3 indicates an electrical malfunction of the MAP sensor or MAP sensor circuit.

NOTE: This test requires the use of Acura sensor test harness part no. 07GMJ-ML80100 or equivalent. Wire colors referenced in testing procedures refer to test harness coloring and not the actual harness wire color.

1. Remove Alternator Sense fuse in underhood relay box for 10 seconds to reset ECU.
2. Start and idle engine.
3. Observe diagnostic LED.

Flashes code 3, proceed to step 5.
Does not flash, proceed to next step.

4. Malfunction is intermittent, check connections at MAP sensor and ECU. End of test.


MAP Sensor Testing:






5. Turn ignition off and connect test harness between MAP sensor and connector.
6. Turn ignition on and check voltage between WHT and GRN terminals on test harness.

Approx. 5 volts, proceed to step 13.
Not approx. 5 volts, proceed to next step.

7. Measure voltage between RED test harness wire and ground.

Approx. 5 volts, proceed to next step.
Not approx. 5 volts, proceed to step 9.

8. Repair open GRN/WHT wire between ECU terminal C16 and MAP sensor. End of test.
9. Turn ignition off.
10. Install test harness between ECU and harness connector. If test harness is not available, carefully backprobe wires at ECU connector.


MAP Sensor Code 3 Testing:






11. Check for voltage between ECU terminals C15 and C16 with ignition on.

Approx 5 volts, proceed to next step.
Not approx. 5 volts, replace electronic control unit.

12. Repair open YEL/WHT wire between ECU terminal C15 and MAP sensor. End of test.
13. Check voltage between WHT and GRN test harness terminals.

Approx. 3 volts, proceed to step 15.
No approx. 3 volts, proceed to next step.

14. Check for short in WHT wire between ECU terminal C11 and MAP sensor. If wire checks OK, replace MAP sensor. End of test.
15. Turn ignition off.
16. Install test harness between ECU and harness connector. If test harness is not available, carefully backprobe wires at ECU connector.


MAP Sensor Code 3 Testing:






17. Turn ignition on and measure voltage between ECU terminals C11 and C16.

Approx. 3 volts, replace electronic control unit. End of test.
Not approx. 3 volts, proceed to next step.

18. Repair open WHT wire between ECU terminal C11 and MAP sensor.
