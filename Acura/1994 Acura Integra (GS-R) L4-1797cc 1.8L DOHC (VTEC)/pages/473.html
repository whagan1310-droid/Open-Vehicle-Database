During Warm Up



Check in Order Listed

1. Idle Air Control Valve (Diagnostic Trouble Code (DTC) 14)
2. Fuel Supply
a. Fuel Injector
b. Contaminated Fuel
3. Engine Coolant Temperature Sensor (DTC 6)
4. Engine Control Modules in Back Up Mode

Back Up mode used when the MALFUNCTION INDICATOR LAMP (MIL) is on.
