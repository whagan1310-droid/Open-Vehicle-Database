Steering: Description and Operation

The power steering system uses an electric motor driven power assist steering. The system consists of a motor inside the steering gearbox, a power unit, a control unit and sensors. This system minimizes parasitic power losses as well as having reduced weight and size compared to conventional hydraulic power steering assist systems. The system provides suitable road feel with reduced kickback.

Battery voltage is supplied at all times to the EPS control unit from fuse 33 through the WHT/YEL wire and to the power unit from fuse 27 through the WHT wire. When the ignition switch is in RUN or START battery voltage is supplied to the control unit from fuse 5 and the YEL wire. The control unit is grounded at G4Oi and G403. The power unit is grounded at T2Oi.

To control the level of steering assist the control unit receives inputs from the steering torque and speed sensor as well as the vehicle speed sensor (VSS). The steering torque sensor tells the control unit how much effort is required to turn the steering wheel. The steering speed sensor tells the control unit how rapidly the steering wheel is being turned. The vehicle speed sensor (VSS) input allows the level of assist to vary in proportion to vehicle speed. This provides appropriate "feel" at all vehicle speeds. When operating, the system requires high current. The signal from the alternator verifies that the charging system is functioning. The current sensor in the power unit provides a signal to the control unit when the motor is moving.

In response to sensor inputs, the EPS control unit commands the power unit to drive the steering gearbox motor. The rate and direction of the motor is varied to provide the proper level of assist. The power unit uses field effect transistors (FET) to control the motor. The field effect transistors act like a set of switches to drive the assist motor.

The EPS control unit has a self-diagnosis function. When the self-diagnosis function detects a fault the control unit turns on the EPS indicator and disables the system. The non-assisted steering will operate normally.
