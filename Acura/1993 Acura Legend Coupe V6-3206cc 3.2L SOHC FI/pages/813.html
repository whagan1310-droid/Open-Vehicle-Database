Rough Idle


SYMPTOM: Rough Idle.

CHECK
1. Electronic Control Module (**)
2. Idle Air Control (IAC) Valve (14)
3. Manifold Absolute Pressure (MAP) Sensor (3) (5)
4. EGR Control System (12)
5. Hoses and Connections

Numbers in parentheses are the blink codes displayed at the MALFUNCTION INDICATOR LAMP. (**) MALFUNCTION INDICATOR LAMP stays on without blinking. Notes on Reading Diagnostic List For ECM trouble code component testing procedures see COMPUTERS AND CONTROL SYSTEM.
