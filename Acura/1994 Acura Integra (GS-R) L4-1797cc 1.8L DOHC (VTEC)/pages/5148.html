Coolant Temperature Sensor/Switch (For Computer): Service and Repair

Engine Coolant Temperature (ECT) Sensor Location:






WARNING: Be sure engine has cooled down to prevent burns.

1. Disconnect 2-wire connector from sensor.
2. Remove sensor from cylinder head.
3. Before installing new sensor, check coolant to see that it is not contaminated.
4. Wrap sensor threads with teflon or pipe-thread tape.

^ Do not wrap sensor bulb area with tape, as it may cause inaccurate readings to be sent to the Engine Control Module (ECM).

5. Torque sensor to 18 Nm (13 ft lb).
6. Refill cooling system with coolant if necessary.
7. Start engine and check for leaks.
